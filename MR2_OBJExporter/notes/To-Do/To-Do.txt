##Changelist##
#[Features]
+ Added multiple "Variants" to each pattern that can be cycled through by clicking the same 
pattern button multiple times in a row
	+ This will change exported patterns for both PNG and TEX exports
	+ Made it easier to add more patterns/variants in the future, possibly even user made ones
+ Expanded color selection for 8bit grid patterns slightly
	= If I use the full 127 colors that are possible, it'll make colors harder to tell apart
+ Changed the way surfaces are drawn and saved so far less memory is used
+ Cleaned up CLUT preview

#[Bug Fixes]
[Model]
+ Exported OBJ file's X coordinates were reversed
+ A few MMJ models that had both Opaque and Semi transparent part would have the faces mixed up

[Texture]
+ When canceling tex import with one already loaded. It deactivated the TEX export button.
+ Jell's CLUT display was drawing each row as a default monochrome gradient
	+ Fix should affect any other TEX file that had this issue
+ Exported grid textures didn't cycle through colors properly
+ PNG: Exported Alpha values between original textures and grid textures were different
	+ This took longer to fix than I'd care to admit...
+ TEX Grid Export didn't export grid patterns by default if no grid patterns were being previewed
+ Exported TEX files didn't handle semi-transparency correctly
+ Didn't know that created surfaces(texture preview window) would erase itself randomly while the 
program was minimized
	+ Lucky that I found this one as it's hard to replicate without waiting ~5-15 min while doing nothing

#[Future Plans]
+ Flat Color Mode that uses 127 different colors for 8bit and 15 colors for 4bit
	= 8bit:127 & 4bit:15 because each color needs two entries: one Opaque and the other Semi-transparent
		= 8bit:128th and 4bit:16th entries are reserved for the Fully Transparent pixel color
	= Flat Color Mode helps enable features like coloring based on:
		- CLUT palette assignments
			= No easy or accesable way to know this atm, would be very helpful
		- Highlighting errors or inconsistencies between Primitive data and Texture data
			= More important for double checking custom model edits
		- Drawing Primitives(Polygons) as single color triangles on single color textures
			= Might help with understanding placement more than just a simple UV PNG export 
				= Should still have a UV PNG export option though
		
+ Scalable Black grid line overlay
+ Interface to change alpha level for exported PNGs 
+ UI Changes to Import/Export buttons
	+ Already built drop down menu interface
+ Toggleable Help/Info Panel that gives explanations of what buttons do as the mouse is hovering over them
	+ Additional Info panel while hovering over the numerous Import/Export buttons
		= This should help some of the confusion on how to use this program
+ Considering making exported files go into an automatically created "Workspace folder
	= Currently dumps everything into the selected directory and is a pain to manage if you don't expect it
